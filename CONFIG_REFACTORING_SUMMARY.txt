═════════════════════════════════════════════════════════════════════════════
TECHNICAL FLOW
═════════════════════════════════════════════════════════════════════════════

Server startup:
   app.main.py
   → ProctoringConfig() instantiated
   → __post_init__() called
   → _init_detection_config() reads DETECTION_CLIENT env var
   → Creates IntelDetectionConfig() OR MediaPipeDetectionConfig()
   → Stores in _detection_config
   
   If DETECTION_CLIENT=intel:
   → ensure_intel_models() downloads 4 Intel OMZ models
   
   → DetectionService created with config
   → Service calls get_detection_client(config)
   → Factory creates IntelDetectionClient OR MediaPipeDetectionClient
   → Client reads thresholds from config proxy properties

At runtime (e.g., face detection):
   DetectionService.detect_gaze(frame)
   → Calls client.detect_gaze(frame)
   → Client reads config.MIN_DETECTION_CONFIDENCE
   → @property get_detection_config() returns active config
   → Returns 0.65 if Intel, 0.70 if MediaPipe
   → Client uses threshold for inference
