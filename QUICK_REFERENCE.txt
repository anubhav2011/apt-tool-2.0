QUICK REFERENCE - DETECTION CONFIG SYSTEM
==========================================

1. SWITCH CLIENTS (Zero code changes)
─────────────────────────────────────

   MediaPipe (default):
   $ export DETECTION_CLIENT=mediapipe
   $ uvicorn app.main:app

   Intel OpenVINO:
   $ export DETECTION_CLIENT=intel
   $ export INTEL_DEVICE=CPU
   $ export INTEL_PRECISION=FP32
   $ uvicorn app.main:app

2. TUNE THRESHOLDS (Edit config.py only)
────────────────────────────────────────

   For MediaPipe:
   - File: app/core/config.py
   - Class: MediaPipeDetectionConfig
   - Edit threshold value (e.g., MIN_DETECTION_CONFIDENCE = 0.75)
   - Restart server

   For Intel:
   - File: app/core/config.py
   - Class: IntelDetectionConfig
   - Edit threshold value (e.g., EYE_ASPECT_RATIO_THRESHOLD = 0.14)
   - Restart server

3. AVAILABLE THRESHOLDS
───────────────────────

   ✓ MIN_DETECTION_CONFIDENCE      (0.0-1.0, higher=stricter)
   ✓ MIN_TRACKING_CONFIDENCE       (0.0-1.0, higher=more stable)
   ✓ GAZE_HORIZONTAL_THRESHOLD     (degrees)
   ✓ GAZE_VERTICAL_THRESHOLD       (degrees)
   ✓ HEAD_YAW_THRESHOLD            (degrees)
   ✓ HEAD_PITCH_THRESHOLD          (degrees)
   ✓ HEAD_ROLL_THRESHOLD           (degrees)
   ✓ EYE_ASPECT_RATIO_THRESHOLD    (0.0-1.0, lower=more sensitive)
   ✓ MIN_IRIS_VISIBILITY           (0.0-1.0)
   ✓ BLINK_EAR_THRESHOLD           (0.0-1.0)
   ✓ GAZE_CONFIDENCE_MULTIPLIER    (>1=boost, <1=reduce)
   ✓ POSE_CONFIDENCE_MULTIPLIER    (>1=boost, <1=reduce)
   ✓ MIN_FACE_PRESENCE_SCORE       (0.0-1.0)
   ✓ MIN_CONFIDENCE_THRESHOLD      (0.0-1.0)
   ✓ EYE_MIN_CONFIDENCE_THRESHOLD  (0.0-1.0)

4. .ENV SETTINGS (Essential only)
──────────────────────────────────

   DETECTION_CLIENT=mediapipe      (or intel)
   INTEL_DEVICE=CPU                (or GPU, AUTO)
   INTEL_PRECISION=FP32            (or FP16, INT8)

6. HOW IT WORKS
───────────────

   At startup:
   ProctoringConfig reads DETECTION_CLIENT env var
   → Creates MediaPipeDetectionConfig or IntelDetectionConfig
   → Stores as _detection_config

   At runtime:
   code accesses config.MIN_DETECTION_CONFIDENCE
   → @property calls get_detection_config()
   → Returns active config's MIN_DETECTION_CONFIDENCE
   → Zero code changes needed!

7. VERIFY ACTIVE THRESHOLDS
────────────────────────────

   Python:
   >>> from app.core.config import PROCTORING_CONFIG
   >>> cfg = PROCTORING_CONFIG.get_detection_config()
   >>> print(cfg.MIN_DETECTION_CONFIDENCE)
   0.65  (if Intel) or 0.70 (if MediaPipe)

8. KEY POINTS
──────────────

   ✓ Each client has its own thresholds
   ✓ Thresholds auto-selected based on DETECTION_CLIENT env var
   ✓ All thresholds in config.py (not in .env)
   ✓ No code changes needed to switch clients
   ✓ Backward compatible with existing code
   ✓ Easy to add new detection backends

9. TROUBLESHOOTING
───────────────────

   Wrong thresholds being used?
   → Check DETECTION_CLIENT env var
   → Verify ProctoringConfig was re-instantiated

   Intel not detecting faces well?
   → Lower MIN_DETECTION_CONFIDENCE (try 0.60)
   → Lower MIN_CONFIDENCE_THRESHOLD (try 0.35)

   Too many false blink detections?
   → Increase EYE_ASPECT_RATIO_THRESHOLD (try 0.20)

   Head pose estimates wrong?
   → Check HEAD_PITCH/YAW/ROLL_THRESHOLD values
   → Adjust POSE_CONFIDENCE_MULTIPLIER (>1 to boost)
